# Atualização visual V6 — Basquete 2D

[Baixar a atualização visual V6](./Basquete2D_Funil_VisualV6.zip?raw=true)

Esta atualização melhora o visual do funil, da alavanca e das cestas. É um pacote de atualização para a cena **Basquete 2D — Funil e Duas Cestas** com a versão V5 já instalada.

## Como instalar

1. Feche o Unity e extraia o arquivo ZIP.
2. Copie a pasta **Assets** extraída para a raiz do projeto NBA, juntando as pastas e substituindo os arquivos solicitados, inclusive os arquivos `.meta`.
3. Abra o projeto, aguarde a importação e use **Tools > Basquete 2D > Abrir funil de duas cestas**.
4. No Inspector, confira a mensagem **Acabamento visual V6** e dê Play.

O pacote preserva a cena e as configurações já salvas. Ele não contém o projeto completo.
